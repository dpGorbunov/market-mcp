# market-mcp

MCP-сервер для российских площадок: **Ozon**, **DNS**, **Яндекс.Маркет**. Поиск с фильтрами, характеристики, отзывы и сравнение кандидатов по реальным отзывам покупателей. Только чтение: без логина, корзины и оплаты.

Форк [eduard256/ozon-mcp-server](https://github.com/eduard256/ozon-mcp-server), см. [что изменено](#что-изменено-относительно-форка).

## Установка

Node 20+ и Chromium для Playwright.

```bash
git clone https://github.com/dpGorbunov/market-mcp.git
cd market-mcp && npm install && npx playwright install chromium
```

Claude Code:

```bash
claude mcp add market --scope user -- node /полный/путь/market-mcp/src/index.js
```

Codex CLI, `~/.codex/config.toml`:

```toml
[mcp_servers.market]
command = "node"
args = ["/полный/путь/market-mcp/src/index.js"]
```

Другие клиенты запускают `node src/index.js` по stdio.

При первом запуске открывается Chromium с постоянным профилем `~/.market-mcp/profile`: площадки проверяют браузер один раз, cookies сохраняются. На macOS окно прячется сразу. Если показана капча, окно выводится на экран и ждёт, пока её решит человек.

## Инструменты

| Инструмент | Назначение |
|---|---|
| `ozon_search` | поиск Ozon: цена, рейтинг, число отзывов, бренд |
| `ozon_filters` | серверные фильтры Ozon для запроса, с id вариантов |
| `ozon_product_details` | характеристики, продавец, описание, `variants` |
| `ozon_product_reviews` | отзывы, распределение по звёздам, свежие плохие |
| `dns_search` | поиск DNS: цена, рейтинг, надёжность, характеристики |
| `dns_product` | полные характеристики по группам |
| `dns_reviews` | отзывы с оценками по критериям и сроком использования |
| `yandex_search` | предложения Маркета с ценами |
| `yandex_card` | карточка: цена, число предложений, рейтинг продавца |
| `yandex_reviews` | отзывы модели (оценок отдельных отзывов Маркет не отдаёт) |
| `compare` | шорт-лист до 6 товаров с любых площадок в одном вызове |

Общий фильтр во всех трёх поисках: `brand`, `ratingMin`, `reviewsMin`, `priceMin`, `priceMax`, `include[]`, `exclude[]`, `sortBy` (`rating`, `reviews`, `price`, `price_desc`, `score`), `pages` (1-5). Параметры каждого инструмента описаны в его схеме, порядок работы и критерии отбора в [`docs/AGENT-GUIDE.md`](docs/AGENT-GUIDE.md).

Ozon читается из внутреннего composer-api (JSON, 0.3-1 с на запрос), DNS и Маркет с отрендеренных страниц (4-7 с). Запросы к одной площадке идут по очереди, к разным параллельно.

## Переменные окружения

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `MARKET_PROFILE_DIR` | `~/.market-mcp/profile` | профиль Chromium с cookies |
| `MARKET_HIDE_WINDOW` | `1` (только macOS) | прятать окно браузера; `0` показывать |
| `MARKET_HEADLESS` | `false` | `true` без окна, но Ozon и DNS тогда выдают капчу |
| `MARKET_CAPTCHA_WAIT_S` | `120` | сколько ждать ручного решения капчи |
| `MARKET_IDLE_MIN` | `720` | через сколько минут простоя закрыть браузер |
| `MARKET_COMPACT` | `1` | компактный JSON в ответах; `0` полный |
| `MARKET_MAX_STR` | `600` | до скольких символов режутся длинные строки |

## Что изменено относительно форка

Оригинал давал три инструмента по Ozon и стартовал headless с чистым профилем, за что получал капчу вместо данных.

- **Браузер.** Один Chromium с окном и постоянным профилем: антибот проходится один раз, cookies живут между запусками. На macOS окно скрыто, показывается только под капчу. Docker удалён: образ собран под amd64 и в headless не проходит антибот.
- **Площадки.** Добавлены DNS и Яндекс.Маркет, 11 инструментов вместо 3.
- **Фильтры.** Серверные фильтры Ozon и общий клиентский отбор с обходом страниц выдачи на всех площадках, включая байесовский `score` с поправкой на число отзывов.
- **Отзывы.** Сортировка `worst`, `best`, `newest`, распределение по звёздам, выборка свежих плохих за N месяцев.
- **`compare`.** Шорт-лист с разных площадок одним вызовом, с долей низких оценок и признаком объединённой карточки Ozon.
- **Ответы.** Компактный JSON: без отступов, пустых полей и ссылок на картинки.
- Описание товара Ozon с сентября 2026 читается из DOM карточки: composer-страница `pdpPage2column` отдаёт 403.

## Разработка

```bash
npm test                  # офлайн-тесты парсеров и фильтров на samples/
node scripts/probe.mjs    # живая проверка всех площадок
```

Пока сервер запущен, профиль занят: для пробы скопировать его (`cp -R ~/.market-mcp/profile ~/.market-mcp/profile-dev`) и запускать с `MARKET_PROFILE_DIR=~/.market-mcp/profile-dev`.

`src/browser.js` браузер, антибот и очереди; `src/rank.js` фильтр и ранжирование; `src/ozon.js` с `src/parse.js`, `src/dns.js` с `src/parse_dns.js`, `src/yandex.js` площадки; `src/compare.js` сравнение; `src/index.js` регистрация инструментов. Логи идут в stderr, stdout занят JSON-RPC.
