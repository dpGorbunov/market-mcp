# market-mcp

MCP-сервер для российских площадок: **Ozon**, **DNS** и **Яндекс.Маркет**. Даёт агенту готовые инструменты поиска с фильтрами, характеристик, отзывов и сравнения кандидатов по реальным отзывам вместо голого браузера. Только чтение, без логина, корзины и оплаты.

Форк [eduard256/ozon-mcp-server](https://github.com/eduard256/ozon-mcp-server). Что изменено относительно оригинала:

- Один Chromium **с окном** и **постоянным профилем** (`~/.market-mcp/profile`). Оригинал стартовал headless с чужим User-Agent и чистым профилем, за что Ozon отдавал капчу вместо JS-проверки. Теперь проверка проходится один раз, cookies живут между запусками; если всё же показана капча, окно ждёт, пока её решит человек (`MARKET_CAPTCHA_WAIT_S`, по умолчанию 120 с).
- Отзывы Ozon: сортировка `worst` / `best` / `newest`, страницы по 30, распределение оценок 5..1, выборка свежих плохих отзывов (`sinceMonths`, `maxScore`).
- Фильтры поиска: серверные фильтры Ozon (`ozon_filters` показывает бренды с id, тип, страну, диапазоны; `highRating`) и общий клиентский отбор для всех трёх площадок: `brand`, `ratingMin`, `reviewsMin`, `priceMin/Max`, `include/exclude` по названию и характеристикам, `sortBy` (в том числе `score`, байесовский рейтинг с поправкой на число отзывов), обход `pages` страниц выдачи.
- DNS (поиск с сортировкой и короткими характеристиками, полные характеристики, отзывы с оценками по критериям и подгрузкой «Показать ещё») и Яндекс.Маркет (поиск с ценами, карточка, отзывы модели).
- `compare`: по шорт-листу до 6 товаров с любых площадок одним вызовом рейтинг, число отзывов, распределение, доля 1-2 звёзд, худшие отзывы, свежие плохие и признак «карточка Ozon объединяет N вариантов».

## Инструменты

| Инструмент | Что возвращает |
|---|---|
| `ozon_search` (query, sort, highRating, filters, + общий фильтр, limit) | товары: название, цена, старая цена, скидка, рейтинг, число отзывов, бренд, URL |
| `ozon_filters` (query) | фильтры Ozon для запроса: ключ, тип, варианты с id (бренд, тип, страна, магазин), диапазоны цены и веса |
| `ozon_product_details` (product, description) | цена с картой/без, наличие, продавец, полные характеристики (страница /features/), описание из DOM карточки (`description=false` пропускает, экономит ~5 с), `variants` (сколько вариантов делят карточку и её отзывы) |
| `ozon_product_reviews` (product, sort, page, limit, sinceMonths, maxScore, maxPages) | отзывы: оценка, текст, плюсы, минусы, дата, «купил», фото; распределение по звёздам; при `sinceMonths`/`maxScore` обход новых страниц и отбор свежих плохих |
| `dns_search` (query, sort, + общий фильтр, limit) | товары DNS: название, бренд, цена, рейтинг, число отзывов, значок надёжности, короткие характеристики, URL |
| `dns_product` (product) | полные характеристики по группам, цена, рейтинг |
| `dns_reviews` (product, limit, sinceMonths, maxScore) | отзывы DNS: общая оценка и оценки по критериям, срок использования, плюсы, минусы, комментарий; распределение по звёздам |
| `yandex_search` (query, + общий фильтр, limit) | предложения Маркета: название, цена, зачёркнутая цена, рейтинг, число оценок, короткие характеристики, URL |
| `yandex_card` (product) | карточка предложения: цена, число предложений, рейтинг продавца, характеристики |
| `yandex_reviews` (product, limit, sinceMonths) | отзывы модели: автор, дата, плюсы, минусы, комментарий, «полезно», вариант; рейтинг, число оценок и отзывов. Оценок отдельных отзывов Маркет не показывает |
| `compare` (products[], worst, recentMonths) | сравнение шорт-листа: рейтинг, отзывы, распределение, `lowSharePct`, `score`, худшие отзывы, свежие плохие, `aggregated`; отсортировано по `score` |

Общий фильтр (`ozon_search`, `dns_search`, `yandex_search`): `brand`, `ratingMin`, `reviewsMin`, `priceMin`, `priceMax`, `include[]`, `exclude[]`, `sortBy` (`rating` / `reviews` / `price` / `price_desc` / `score`), `pages` (1-5).

## Как искать лучший товар

1. `ozon_filters` + `ozon_search` с `pages: 3, reviewsMin: 100, ratingMin: 4.7, sortBy: "score"`; то же `dns_search` (`sort: "rating"`) и `yandex_search`. `include` отсекает лишнее по характеристикам («30 см», «2 конфорки»).
2. `compare` по 3-6 кандидатам: смотреть `lowSharePct`, `worst[]`, `recentLow` (что ломается в свежих партиях) и `aggregated` (рейтинг Ozon может быть общим на несколько моделей одной карточки).
3. Рейтинг DNS привязан к конкретной модели, у Ozon к карточке с вариантами, поэтому при расхождении верить DNS и худшим отзывам.

Данные Ozon берутся из внутреннего composer-api (JSON, 0.3-1 с на запрос после первого прохода антибота). DNS и Маркет читаются с отрендеренных страниц из того же браузера (4-7 с на страницу). Запросы к одной площадке идут по очереди, к разным параллельно.

## Установка

Нужны Node 20+ и Chromium для Playwright.

```bash
git clone https://github.com/dpGorbunov/market-mcp.git
cd market-mcp && npm install && npx playwright install chromium
claude mcp add market --scope user -- node /полный/путь/market-mcp/src/index.js
```

Другие клиенты (Claude Desktop, Cursor, Codex и т.д.): команда `node src/index.js` по stdio, см. `docs/`.

Docker-образ оригинала собран только под amd64 и не проходит антибот (headless), поэтому здесь не используется.

## Переменные окружения

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `MARKET_PROFILE_DIR` | `~/.market-mcp/profile` | профиль Chromium (cookies) |
| `MARKET_HEADLESS` | `false` | `true` - без окна (Ozon/DNS в этом режиме выдают капчу) |
| `MARKET_CAPTCHA_WAIT_S` | `120` | сколько ждать ручного решения капчи |
| `MARKET_IDLE_MIN` | `10` | через сколько минут простоя закрыть браузер |

## Разработка

```bash
npm test                  # офлайн-тесты парсеров и фильтров на samples/
node scripts/probe.mjs    # живая проверка всех площадок (открывает окно браузера)
```

Пока MCP-сервер запущен, профиль занят: для живой проверки скопировать его (`cp -R ~/.market-mcp/profile ~/.market-mcp/profile-dev`) и запускать пробу с `MARKET_PROFILE_DIR=~/.market-mcp/profile-dev`.

`src/browser.js` - браузер, антибот, очереди по площадкам; `src/rank.js` - общий фильтр и ранжирование; `src/ozon.js` + `src/parse.js` - Ozon; `src/dns.js` + `src/parse_dns.js` - DNS; `src/yandex.js` - Маркет; `src/compare.js` - сравнение; `src/index.js` - регистрация инструментов. Логи только в stderr, stdout занят JSON-RPC.
