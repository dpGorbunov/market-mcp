# Как агенту пользоваться market-mcp

Цель инструментов: выбирать товар по реальным отзывам покупателей, не по рейтингу в сниппете и не по поисковой выдаче.

## Порядок работы

1. Широкий поиск с фильтрами на двух площадках сразу:
   - `dns_search(query, sort="rating", pages=3, reviewsMin=100, ratingMin=4.7, sortBy="score")`
   - `ozon_search(query, pages=3, highRating=true, reviewsMin=100, ratingMin=4.7, sortBy="score")`
   - Нужные характеристики отсекать `include` / `exclude` по названию и коротким характеристикам: `include=["30 см", "2 конфорки"]`.
   - Габариты и серверные фильтры Ozon: сначала `ozon_filters(query)`, потом ключи в `ozon_search(filters={brand: "7577796"})`.
2. Шорт-лист из 3-6 кандидатов проверить одним вызовом `compare(products=[url...])`. Читать `lowSharePct`, `worst[]`, `recentLow[]`, `aggregated`.
3. По финалисту дочитать отзывы: `dns_reviews(product, maxScore=3)` и `ozon_product_reviews(product, sort="worst")`, затем `ozon_product_reviews(product, sinceMonths=12, maxScore=2)` для свежих поломок.
4. Габариты и полные характеристики: `dns_product(product)`, `ozon_product_details(product, description=false)`.
5. Цену сверить на Маркете: `yandex_search(модель)`, у карточек модели есть `yandex_reviews`.

## Критерии отбора

- Рейтинг по конкретной модели не ниже 4.7 при 200+ отзывах (для редких категорий 100+).
- Доля оценок 1-2 звезды (`lowSharePct`) не выше 3%.
- За последние 12 месяцев нет серии одинаковых поломок в `recentLow`.
- Рейтинг DNS привязан к конкретной модели, ему верить больше. Карточка Ozon часто объединяет модели и цвета (`variants` > 1, `aggregated`), её рейтинг общий.
- Отзывы о доставке (разбито, помято) не считать дефектом товара.
- Товар без отзывов на трёх площадках не рекомендовать как проверенный, а помечать «покупка вслепую».

## Ограничения инструментов

- DNS грузит страницы по 5-20 с, запросы к DNS идут по очереди. `compare` с 4+ товарами DNS может не уложиться в таймаут: делить на два вызова по 2-3.
- Ozon: описание карточки и полные характеристики берутся отдельно, `description=false` экономит 5 с.
- Маркет: у карточек продавцов отзывов нет (`noReviews`), отзывы есть у карточек модели; оценок отдельных отзывов Маркет не показывает (`score=null`).
- Цены DNS в `dns_search` верные, в `dns_product` поле `price` может быть неверным (берётся первое число с ₽).
- Кириллица в `include` / `exclude` сравнивается без учёта регистра, «ё» приравнивается к «е».

## Как писать вывод для человека

Таблица: модель, цена и где, рейтинг и число отзывов, доля плохих, две-три цитаты из худших отзывов. Отсеянные модели одной строкой с причиной. Без пересказа описаний продавцов.
